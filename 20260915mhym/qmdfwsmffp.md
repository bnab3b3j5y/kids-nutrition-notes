# 为什么说16年前没办独生子女证的人亏大了？

> 更新时间：2026-09-15 (UTC+8)

我家孩子是15年末出生的，当时因为有很多其他事要处理，所以就没有立马给他办独生子女证，结果在16年的时候办被通知不能办的。当时觉得不办就不办，有什么大不了，但最近我一同事退休了，不知道为什么退休工资比别人多一些，他还给我说我没办独生子女证亏大了！为什么他这么说啊？难道可以多拿钱？

因为独生子女证在16年年初就停止办理了，之前领到独生子女证的夫妻和孩子，都可以享受到很多福利优惠政策。根据相关政策，独生子女从领证到14周岁之前，每个月都可领取5-20元的独生子女保健费。同时在农村分配集体收益时，独生子女家庭还可以多分到一份。在读书、就医方面还给予了特殊的优待，当父母达到一定年龄时，国家还会根据情况发放奖励扶持金等等。所以说16年前没办到独生子女证的人亏大了。
《独生子女父母光荣证》在2002年9月1日之前称《独生子女证》（有地区称《独生子女光荣证》），是自愿终身只生育一个子女的夫妻，国家发给《独生子女父母光荣证》作为一种荣誉。获得《独生子女父母光荣证》的夫妻，按照国家和省、自治区、直辖市有关规定享受独生子女父母奖励。
根据相关规定，居民办理独生子女证可以享受以下几方面的政策优惠：

- 1. 从领证之月起到子女十四周岁止，每月发给五至二十元的独生子女保健费；
- 2. 农村集体经济组织分配集体经济收益、征地补偿费时，对独生子女家庭增加一人份额；
- 3. 在划分宅基地、扶持生产、介绍就业等方面，对独生子女家庭给予照顾；
- 4. 有关部门和单位根据实际情况，对独生子女入托、入园、就学、就医、就业以及就业培训等方面给予优待；
- 5. 农村居民中的独生子女父母或者生育两个女孩的父母，达到国家和省人民政府规定的年龄时，由人民政府发给奖励扶助金；
- 6. 人民政府兴建的养老机构在接纳有子女的老人时，对独生子女父母和农村生育两个女孩的父母给予优先优惠。
但在2016年1月1日起，国家出台相应的独生子女奖励政策规定，对自愿生育一个孩子的夫妻，不再发放《独生子女父母光荣证》，不再享受独生子女父母奖励费等相关奖励优待政策。
