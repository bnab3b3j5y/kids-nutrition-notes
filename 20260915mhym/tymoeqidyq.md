# 重庆试管选孩子费用明细总共多少？需要支付的总费用是多少？

重庆试管婴儿选孩子总费用是多少？

1.术前检查费用

在进行助孕受精之前，医生会对助孕受精夫妇进行全面的身体检查，以确认是否存在任何可能危及助孕受精成功的因素。此次测试的费用约为2000元。一般来说，在进行试管婴儿治疗之前，夫妻双方都需要进行术前检查，以排除一些不适合试管婴儿的疾病，比如传染病、不适合孕妇的疾病等。

2. 推广费

经过常规体检和调理后，医生会根据患者的检查结果为患者制定相应的计划。因为每个人的计划不同，而且药品是从国内进口的，所以有额外的费用和验血费用。费用将根据时间长短而有所不同。

3. 实验室胚胎培养

实验室胚胎培养通常按频率进行。实际规格必须考虑当地经济水平和医院类型。对于胚胎培养的时间段会有不同的规定。一般来说，培养第5-7天的胚胎比培养第3天的胚胎要贵一些，这部分的费用大概在1-200万元左右。

4、胚胎着床前诊断及筛查费用（适用于第三代试管婴儿）

第三代试管婴儿胚胎培养出来后，会对胚胎进行检查，挑出不良或异常的胚胎，这样可以保证胚胎在移植前的身心健康。移植成功后，流产的几率会降低，胎儿畸形的风险也会降低。可能性会降低。成本可能在300-5亿元左右。

5.移植费用

成功排卵后，医生会进行助孕受精和母细胞移植。如果有多于一个胚胎，医生会建议患者进行冷冻保存，这需要IVF取卵和胚胎冷藏的医疗费用。这支笔的成本在5000-10000元左右。

6. IVF后卵泡期的适用费用

一般来说，黄体酮适合在IVF前保护胎儿。给药方法助孕括皮下注射、阴道填塞和口服给药。根据所选药品品牌的不同，费用约为1000-3000元。

7. 验孕费

试管婴儿移植后第14天，试管婴儿患者必须到医院检测血hcg，以确认移植的胚胎是否着床。如果助孕埋成功，将进行B超检查。费用以医院标准为准。
