# 乳痛太可怕，8个方法教你避免乳痛

> 更新时间：2026-09-16 (UTC+8)

医生，我来月经前会出现乳房胀痛，严重时，碰都不能碰，来完月经，乳房肿痛就会缓解；每个月都要经历这种痛苦，怎么办呀，我都有心理阴影了。

医生，我经常乳房胀痛，来月经也痛，不来月经也痛，好影响我的工作和睡眠，我在美容院做了乳房保健，还是没有效果怎么办呀，我快抑郁了。

医生，我乳头好痛，碰都不能碰，会不会得什么病了，怎么办？

目前普遍认为，乳痛的发病原因是卵巢内分泌功能紊乱引起乳腺间质和腺体出现不度的增生和复旧不全造成的结构紊乱。比较经典的病因学说认为：雌激素与孕激衡失调，表现为黄体期孕激素分泌减少、雌激素的量相对增多，致使雌激素长期乳腺组织而缺乏孕激素的节制与保护作用，导致乳腺导管和小叶在周而复始的月中增生过度而复旧不全，从而发生乳腺增生病，就是我们女性朋友都惧怕乳痛症啦。

下面，给大家介绍下我们攀枝花市妇幼保健院乳腺甲状腺专科对乳痛治疗的特色疗法：

**01******

**（三才）乳腺低频理疗**

利用低频的电流和脉冲，对乳房的刺激，调节人体内部环境，促进血液循环，兴奋神经肌肉组织，提高组织的活力，从而治疗起到急慢性疼痛的作用。适应症:乳腺增生、乳痛症、乳腺囊肿、乳腺炎。

**02******

**导管灌注治疗**

针对乳痛溢液、乳管扩张症，定向疏通堵塞导管，清除导管内异常分泌物。

**03******

**乳腺推拿**

手法:按、揉、推。作用于人体穴位。通过局部刺激，可疏通经络，调动机体抗病能力，从而达到防病治病、保健强身的一种技术操作。

**04******

**穴位敷贴**

穴位敷贴是中医内病外治的传统方法，疗效确切。取穴包括膻中、气户、乳根、期门，辅以足三里穴等。还可配合红外线，通过热效应刺激穴位，继发经络之气，达到疏通经络、条畅气血之效。中医认为疼痛多由于局部气血凝滞、阻塞不通所致，疏通经络气血有助于止痛。

**05******

**耳穴压豆疗法**

简单易行、疗效肯定。通过调节下丘脑-垂体-性腺轴的功能，可以调节体内激素水平的异常，恢复激素代谢节律，起到舒经通络、调和气血的作用，从而改善乳痛症状。

**06******

**中药热奄包外敷**

采用中药热敷结合穴位刺激的一种中医外治疗法，整合了中药治疗+穴位刺激+温热疗法的优点。热奄包通过热蒸作用，可使局部的毛细血管扩张，血液循环加速，从而增强代谢，促进炎症和淤血吸收，起到温经通络、舒筋活络、调和气血、消肿止痛、祛湿祛寒的作用。

**07******

**灸法、针灸**

灸法的作用：温经散寒、扶阳固脱、消瘀散结、防病保健。适用于寒凝血滞、经络痹阻、气血凝滞所引起的乳腺疼痛。常见的有隔物炙、热敏灸、艾炷灸、直接灸、隔盐灸、隔药饼灸、雷火针温针灸、艾箱灸、脐灸。

**08******

**刮痧**

乳痛原则：疏肝理气，散结止痛，通三焦，肝乳痛经验穴：三焦经治肝气郁结 降胆火化肝火注意事项：四小时内不宜洗澡，避免吹风.

****

**日常生活如何调养**

1. 注意营养均衡，多吃蔬菜水果和低脂肪高纤维的食物，禁食辛辣刺激及富含激素的食物，如油炸食品、高脂肪肉类、动物内脏、蜂王浆以及含有膨大剂、催化剂的食品和食用饲料喂养的鸡、鸭、鱼、猪等；

2. 保持心情舒畅，情绪不佳时多与朋友家人沟通，适量运动，规律作息，不熬夜；

3. 选择合适的内衣，以免压迫乳房产生不适感；

4. 远离丰胸产品，禁止不规范的乳房疏通按摩；

5. 定期进行乳腺彩超检查，无症状人群可每年检查一次，乳痛症状明显或有乳腺增生结节病史，3-6个月检查1次。
