# 微导诊|“肌肤之亲，爱之体验”—— “袋鼠式护理”倾听爸爸妈妈的心跳

> 更新时间：2026-09-17 (UTC+8)

“抱宝宝我还不会么？不就是把宝宝放在自己温暖的怀抱里么？”

新爸爸看到这里一脸迷茫，然后，我们今天要说的是一种神奇的拥抱：“袋鼠抱”，是“袋鼠式”护理的一个重要环节。

“袋鼠式”护理是20世纪80年代初发展起来的，主要针对早期新生儿的一种特殊的护理方式，它适合每一个刚出生的孩子，包括早产儿和足月健康儿，可持续至宝宝三岁后。

**“袋鼠式”护理**

国外的“袋鼠式”护理（kangaroo mothercare,KMC）在国内又被称作是皮肤接触式护理(Skinto Skin Care，SSC)，是指新生儿母 (父) 亲模仿袋鼠照顾婴幼儿的方式，让新生儿赤裸以直立位或俯卧位的方式趴在母 ( 父 ) 亲的胸口，与新生儿的皮肤直接接触，提供他( 她)所需的温度，同时观察新生儿的暗示并给予及时的抚慰。实施袋鼠式护理的理念最初是因为母亲可提供类似于子宫环境，因而可以减少新生儿刚出生时由于外界刺激所产生的压力，同时促进新生儿迅速适应宫外的环境。

国外学者在数十年的研究中发现，KMC不论是对新生儿还是产妇自己本身都有着积极地促进作用，对新生儿来讲，在新生儿刚出生后，与母亲立即进行皮肤接触可迅速恢复体温尤其是在剖宫产术后，由于与母亲的分离时间较长，常常会出现新生儿体温不升的现象，因此袋鼠式护理取代暖箱为新生儿提供适宜的温度的优势就尤为明显，同时在稳定新生儿的基本生命体征，促进新生儿体格发育、降低新生儿疼痛敏感度、满足新生儿心理需求，最终实现降低新生儿患病率和死亡率。其次，对产妇的研究发现表明，KMC 的实施有助于减轻产妇的焦虑、紧张的情绪，尤其是行剖宫产的产妇，效果尤为突出 ，同时实施 KMC 可以转移产妇的部分注意力，缓解产妇术后伤口的疼痛，加快子宫收缩，减少产后出血，并且刺激脑垂体分泌缩宫素，有效建立泌乳反射促进纯母乳喂养，最终加快产妇身体复原，缩短住院时间，减轻医疗负担。同时实施KMC不是产妇一人的事情，需要家庭成员的积极配合，共同参与KMC不仅提高了照顾新生儿的技能，同时还减轻了产妇的精神压力。

**幸福感**

纵观国内外的研究发现KMC的母亲有更高的幸福感：86%母亲感觉通过实施KMC可增强自己“做妈妈”的感觉； 100%母亲认为“KMC可以为孩子提供必需的温度”，大量研究已经证实KMC对促进新生儿体温恒定有积极作用；其中 91%的母亲认为“KMC可以安慰孩子，缓解新生儿紧张害怕”； 同时袋鼠式护理有利于增强母子情感，密切亲子关系；89%的母亲指出，就算是产后伤口的疼痛，她们也愿意继续坚持实施KMC 。

幸福

今年初，我院产科在产后妈妈中开展了家庭参与式“袋鼠式”护理，这一举措大大地满足了宝宝对温暖、母乳、安全的需要，促进宝宝中枢神经系统的发育，还能促进母亲乳汁的分泌，调整妈妈的情绪，预防产后抑郁，使母婴双方受益匪浅，大大提高了病人住院体验感，获得良好的社会反响。

现在袋鼠式护理已形成常规在产后妈妈中广泛开展，但剖宫产产妇由于术后第一天伤口疼痛，很多妈妈不敢做袋鼠抱，针对这一问题，产科护士们动员爸爸们上阵，但是在临床上，我们见到的通常是新生儿与妈妈的“袋鼠抱”，而与爸爸的拥抱少之又少；但其实在很多时候，并不是爸爸们不愿意体验，而是在他们心中觉得这是妈妈的事，应该由妈妈来完成，而当剖宫产术后或者产后身体虚弱的妈妈不能进行“袋鼠抱”时，他们就自动放弃了这一良好举措。

Veland，Uvnas-Mobergand Nissen（2012）的一项对照研究结论也指出，如果母亲无法提供肌肤接触，父亲与新生儿进行肌肤接触则是有价值的替代方法，可帮助新生儿尽快适应外环境，维持生命体征，也可促进父亲的照护角色。

**新爸爸的初体验**

我们在新生儿照护需要“袋鼠抱”的时候，特意引导了几位父亲去完成，我们在过程中观察新生儿与父亲契合的情况，结果显示父亲与新生儿的肌肤接触可以减少啼哭时间，使宝宝情绪更稳定、状态更舒适，大大降低了新生儿出生早期的应激反应。其中有父亲激动地表示：在“袋鼠抱”过程中的体验非常奇妙！小小软软的身体趴在怀里，安静地听着彼此的呼吸与心跳声，小宝宝逐渐安静下来，安然进入了梦乡，心一下就柔软了！
