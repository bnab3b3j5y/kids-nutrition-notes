# 新生儿和宝宝败血症的信号有哪些？

> 更新时间：2026-09-11 (UTC+8)

新生儿败血症是我们熟悉的一种疾病。同时，它也是一种严重的疾病。尤其是孩子出现异常反应后，一定要引起重视，及时进行合理的检查。

新生儿败血症症状

1. 母乳喂养可减少吸吮无力。 新生儿吸奶量明显减少。他们似乎没有意识到饥饿。吸吮时间短且弱，喂食时容易发生窒息。

2. 叫声低得像“猫”。 3336 患有败血症的婴儿经常停止哭泣，或只哭几次就停止哭泣，且哭声低沉。

3、体温不升，手脚冰凉。 新生儿患败血症时，体温不是高，而是低。测量体温时在35.5以下，宝宝手脚冰凉。

4、全身无力，四肢活动少。 新生儿屈肌肌张力较高，弯曲四肢，或不断运动，小手会紧紧抓住你的手指；而患有败血症的宝宝，四肢和全身都比较无力，如果拉扯他们的上肢，他们也会没有明显的屈曲反应。如果你一松手，他的上肢就会自然垂下，双手也不会抓住你的手指，四肢也很少活动。

5、反应低、嗜睡： 正常新生儿受到刺激时能做出适当的反应，如醒来、凝视、微笑等；而患有败血症的婴儿则表现出反应能力低下、无精打采或嗜睡。

6. 黄疸不消退或复发。 正常生理性黄疸应逐渐消退。新生儿败血症时，生理性黄疸不消退反而加重，或黄疸消退后又出现黄疸。

7、体重不增加： 正常新生儿出生后有生理性体重下降，但下降时间在出生后34天比较为明显，下降幅度不超过出生体重的10%。出生后会逐渐恢复，出生后7天左右就会逐渐恢复。宝宝在大约10 天后恢复到出生体重。从此以后，宝宝的体重每天增加50克左右，满月时宝宝的体重增加到750克以上。患有败血症的新生儿，生理性体重减轻超过正常范围，并且在体重生长期体重不增加。

8、休克： 面色死灰，呼吸停止，血压下降，无排尿或尿量很少，表明处于休克状态，需要及时就医。

新生儿败血症检测

1、外周血白细胞计数及分类：血白细胞计数5109=''l=''0.2提示细菌感染。

2、血小板计数：血小板计数100109/L提示新生儿败血症的可能。

3.紧急期蛋白： C反应蛋白15g/ml提示细菌感染，ESR15mm/h。

4. 血培养检查： 血培养阳性可明确诊断原因。疑似感染患儿入院后服用抗生素前需抽取外周血进行培养，并严格遵循无菌操作流程，防止污染。如果孩子使用过作用于细胞壁的抗生素，如青霉素类、头孢菌素类等，可以使用高渗培养基进行L型细菌培养。如果怀疑厌氧菌感染，可以进行厌氧菌培养。

5.其他部位培养： 脐部、尿液、粪便或其他局部感染灶的培养。

6.放射学检查： 对有呼吸道症状的儿童应进行胸部X线检查。

7、病原体抗原检测：种方法如对流免疫电泳、乳胶凝集试验、血凝抑制试验等方法。

新生儿败血症的诊断

1.呼吸困难。这是比较常见的症状。根据严重程度略有不同。不太严重的症状助孕括呼吸急促；严重的症状助孕括呼吸衰竭，只有人工通气后才能恢复正常。

2、心跳加快，心跳速度超过一定范围。心脏周围的循环灌注较差，呈蓝紫色。

3.低血压。

4.酸中毒或血糖水平不在正常范围内，表现为低血糖或高血糖。

5、体温不稳定。其中，约15%的儿童无法保持相对恒定的体温，体温不升高或发烧。

6.胃肠道异常，导致呕吐、腹胀等。

7、活动量明显减少或经常处于昏睡状态，或感觉异常烦躁。

8、身体痉挛；

9、身体出现瘀点或瘀点。
